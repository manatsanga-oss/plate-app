ผู้ใช้แจ้งว่า **import/re-import ไฟล์ workflow ที่กำลังคุยกันล่าสุดใน n8n เสร็จแล้ว ตั้ง credential แล้ว กด Publish แล้ว** ให้ทำทันทีโดยไม่ต้องถามซ้ำ:

1. ยิงทดสอบ webhook ของ workflow นั้น (ใช้ action ที่ปลอดภัยก่อน เช่น list/status แล้วค่อยทดสอบคำสั่งจริงถ้าจำเป็น)
2. ถ้ามี workflow มากกว่า 1 ไฟล์ค้างอยู่ ให้ทดสอบทุกไฟล์ที่ค้าง
3. รายงานสั้น ๆ: ผ่าน/ไม่ผ่าน ตรงไหน ถ้าไม่ผ่านให้แก้ไฟล์ในโฟลเดอร์ `C:\Users\manat\OneDrive\New folder` แล้วบอกให้ re-import อีกครั้ง (ระบุชื่อไฟล์และโหนดที่ต้องตั้ง credential)

ถ้าผู้ใช้พิมพ์ข้อความต่อท้าย (เช่น `/re ทั้งสองไฟล์`) ให้ถือเป็นรายละเอียดเพิ่มเติมของสิ่งที่ import มา
